# Portafolio de Carlos Pablo Bautista

Base del portafolio profesional construida con Next.js, React, TypeScript y Tailwind CSS. El proyecto utiliza App Router y genera una exportación estática en `out/`, preparada para un futuro despliegue en Cloudflare Pages.

## Desarrollo local

```sh
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Validaciones

```sh
npm run lint
npm run typecheck
npm run build
```

El build de producción crea el sitio estático en `out/`.
